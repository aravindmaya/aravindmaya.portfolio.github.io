# Quick Deployment Checklist

## Before Uploading
- [ ] All files are ready in your local project folder
- [ ] You have Hostinger login credentials
- [ ] Domain `aravindmaya.com` is connected to Hostinger

## Upload Process
- [ ] Logged into Hostinger hPanel
- [ ] Opened File Manager → `public_html` folder
- [ ] Deleted default files (if any)
- [ ] Uploaded `index.html` to root
- [ ] Uploaded `about.html` to root
- [ ] Uploaded `fun.html` to root
- [ ] Uploaded `_next/` folder (entire folder)
- [ ] Uploaded `Images/` folder (entire folder)
- [ ] Uploaded `projects/` folder (entire folder)
- [ ] Uploaded `home/` folder
- [ ] Uploaded `videos/` folder
- [ ] Uploaded all root files (favicon.ico, favicon.svg, manifest.json, sw.js, .htaccess, etc.)

## After Upload
- [ ] Website loads at www.aravindmaya.com
- [ ] Homepage displays correctly
- [ ] All images load
- [ ] Navigation works
- [ ] About page works
- [ ] Fun page works
- [ ] Project pages work
- [ ] Mobile view works
- [ ] SSL certificate is installed (for service worker)
