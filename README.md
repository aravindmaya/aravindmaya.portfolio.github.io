# Aravindh Maya - Portfolio Website

Portfolio website showcasing product design and engineering work.

## Features

- Responsive design with dark mode support
- Interactive design tips section
- Project case studies
- Service worker for offline functionality
- Optimized performance with Next.js static generation

## Structure

- `index.html` - Main homepage
- `projects/` - Individual project case studies
- `about.html` - About page
- `fun.html` - Fun projects showcase
- `Images/` - Project images and assets
- `_next/` - Next.js static assets

## Deployment

This site is configured for GitHub Pages deployment. Simply push to the repository and GitHub Pages will automatically deploy.

## Local Development

Open `index.html` in a browser or use a local server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve
```
